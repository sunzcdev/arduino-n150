# n150-uno-box v10 —— 桌面音乐灯盒（UNO R3）

**一个不需要电脑的成品**：插上电就自动演奏 5 首曲子，灯随音高变色打拍。

## 硬件

| 件 | 脚 | 状态 |
|---|---|---|
| 无源蜂鸣器（第一声部） | D3 | 已接 ✓ |
| RGB 灯 红/绿/蓝 | D5 / D6 / D9 | ✓ 全通（D9 已重插；实测 2506~2711mV 钳位） |
| 按键（可选） | D2 → GND | 未接，接上即生效 |
| 电位计 10k（可选） | 中间脚 A0，两侧 5V/GND | 未接，接上即生效 |
| 空闲脚 | D10 / D12 / A1~A5 | D10 作蓝灯应急替代脚；⚠️ 实测 D10 上仍插着旧线（3852mV 高阻可疑），别当空脚用 |

## 行为

- **上电即演**：自检（红→绿→蓝，蓝灯多停 1 秒）→ 从第 1 首开始 → 依次循环
- **按键**：短按=下一首；长按 ≥0.7s=暂停/继续
- **电位计**：速度 0.5x~2.0x（自动检测，未接=1.0x）
- **灯效**：音高→色相（红→蓝 0.66 圈，按本曲音域归一化）+ 脉冲 `v=0.78+0.22*min(1,d/700)`，与原 `play_mix.py` 观感一致
- **电脑端命令**（收到即暂停自动演奏，`g` 收回）：
  `p<Hz>,<ms>` 单音｜`f<r>,<g>,<b>` 脉冲打拍｜`c<r>,<g>,<b>` 持续色｜`w<0-8>` 图案｜
  `l<n>,<v>` 单灯｜`k<ms>` 脉冲衰减｜`a<ms>` 步长｜`t` 自检｜`0` 全停
- **v10 新命令**：`g` 恢复自动演奏｜`n` 下一曲｜`s<1-5>` 跳曲｜`v<30-300>` 固定速度%(v0=交还电位计)｜
  `m0/m1/m2` 灯脚映射（m2 = 蓝灯改走 D10）｜`P` 电位计诊断｜`Z` 灯路电测

## 生成与部署

```bash
# 1. 生成曲库（songs.h）与 v10 源码（由 v9 外科式增补，保留已验收的灯效/命令）
python3 tools/make_songs.py
python3 tools/make_v10.py

# 2. 投到行者并编译烧录（注意：先删远端目录，否则 scp -r 会套子目录）
ssh xingzhe 'rm -rf ~/arduino/n150-uno-box'
scp -q -r n150-uno-box v10_verify.py xingzhe:~/arduino/
ssh xingzhe 'cd ~/arduino/n150-uno-box && arduino-cli compile --fqbn arduino:avr:uno . \
  && arduino-cli upload -p /dev/ttyUSB0 --fqbn arduino:avr:uno .'

# 3. 实测（真板子，判据自动汇总）
ssh xingzhe 'python3 ~/arduino/v10_verify.py /dev/ttyUSB0'
```

资源占用：flash 17474/32256 (54%)，SRAM 572/2048 (27%)（曲库在 PROGMEM，不占 SRAM）

## 实测记录（v10.2 全部通过）

```
✅ A 电位计不误判   A0 原始1006 抖动33 → "接了? 否"  实际速度 100%
✅ B 节奏无漂移     小星星→下一首 实测 27.8s（期望 27.1s）
✅ C 回到有何不可   1/5 有何不可 691音/199s
✅ D 蓝D9 断路复现   上拉HIGH 10/10 上升 8us → BAD
```

### 修复史
- v10.0 → v10.1：顺序播放改为绝对时间轴（原先每音 `millis()+dur`，被阻塞式灯效逐音拖慢，42 音短曲慢 4~5s）
- v10.1 → v10.2：电位计检测加"上拉上升时间"判据（原先只看抖动，悬空 A0 稳定在 225 被误判为已接 → 全局降速 0.83x）
- v10.2 → v10.3：`Z` 判据从"数字读数+上升时间"改成 **ADC 实测电压**。原因：逻辑阈值 0.6×VCC=3.0V 判不准蓝色 LED（其钳位 2.6~3.2V），且上拉后只等 2ms 时结电容未稳 → **对着好线报"断路"**。新增自校准基准脚（裸脚 A1 实测 5000mV 报 BAD；真实通道 2249~3222mV 报通路）
